# data-science-portfolio

My data science portfolio, published with **GitHub Pages**.

**Live site:** https://ZIY428.github.io/data-science-portfolio/

## What this is

A single-page portfolio describing who I am, the tools I use, and the data
science projects I have completed. The site is built from `index.md` in the
repository root, which GitHub Pages serves automatically as the entry file.

## Structure

```
data-science-portfolio/
├── index.md                     <- the website (Pages entry file)
├── figures/
│   └── flight_tracks_frame.png  <- visualization shown in the project showcase
└── README.md
```

## Publishing

Settings → Pages → Build and deployment → **Deploy from a branch** →
branch `main`, folder `/ (root)` → Save.
